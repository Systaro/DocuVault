File listings show what is actually in a file instead of one identical
icon per row, and every space says who can reach it.

### Thumbnails in file listings

Images and SVGs preview directly, and HTML files render as a scaled-down
picture of the real page — so a folder of presentations is finally
distinguishable at a glance instead of nine identical rows. Everything
else gets a proper per-extension icon.

Previews load only as rows scroll into view, so a folder full of heavy
pages does not render them all at once. Shared folder links show the same
thumbnails.

![Thumbnails in file listings](assets/changelog/v0.4.0/thumbnails.png)

### Members in the space sidebar

Each space now shows who can reach it, expandable into a list with each
person's role and where their access comes from — granted directly, held
through a team, or inherited from a parent space. Sub-spaces list the
people who reach them through their parent instead of appearing to have
no members at all.

Visible to anyone with access to the space, not just admins.

![Members in the space sidebar](assets/changelog/v0.4.0/members.png)

### A quieter file browser

`.gitkeep`, `.gitignore`, `.github` and friends are repository plumbing,
not documents, and are now hidden while *Pretty names* is on — the same
toggle that hides file extensions. Turn it off to see the repository
exactly as Git has it. Folders are filtered too, not just files.

![Hidden dot-entries](assets/changelog/v0.4.0/hidden-files.png)

### Sharing

Images embedded in a shared document now actually load. Sharing a
document has always carried its companion files with it — images, CSS and
scripts sitting next to it inherit the link's access — but the viewer
asked for them under the wrong path, so every embedded image in a shared
document came up broken.

Shared documents also keep a readable column instead of stretching text
across the full width of a wide monitor, matching the in-app view.

![Shared documents](assets/changelog/v0.4.0/sharing.png)

### Editing

- Renaming a document title now actually saves. Previously the new title
  showed on screen, the *"last edited"* stamp never moved, and the old
  title came back on the next reload
- Long titles wrap onto a second line instead of being silently cut off
  with no sign the title continued

### MCP server

- `create_document` / `update_document` accept PDF, Word, Excel,
  PowerPoint, OpenDocument, RTF and CSV files, stored byte-for-byte
- `download_document` saves binary files intact rather than mangling them
  as text, and `read_document` now points you at it instead of returning
  garbled output
