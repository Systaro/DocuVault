Moving something no longer breaks the trail back to it.

### A document keeps its author when it moves

Moving a document used to hand its authorship to whoever moved it, because a
move is a single commit that adds one path and removes another — so the newest
name on the file was the mover's. History now follows the move: the creator,
the full list of versions and every earlier version's content stay with the
document wherever it goes, including into another space.

![A moved document still crediting the person who wrote it](assets/changelog/v0.7.0/creator-survives-move.png)

### Links to a moved document still work

Anyone who saved a link to a document that has since been moved or renamed now
lands on the document instead of a dead page. This holds for every kind of
file, not only Markdown, and whether the link was to the editor or the preview
— including a document that has moved twice, or one that travelled inside a
folder somebody renamed.

### Search finds spaces and groups, not just documents

Typing the name of a space used to bury it under every document that happened
to mention it. Spaces and groups now come first, with their own icons, and
clicking one opens it. File types are easier to tell apart at a glance too:
spreadsheets, diagrams, data files and plain text no longer share one icon.

![Search showing a space above the documents that mention it](assets/changelog/v0.7.0/search-spaces.png)

### Videos play, and nothing opens as a blank page

Video and audio files play in place, and can be scrubbed without waiting for
the whole file. Anything DocuVault has no viewer for — an archive, a Word
document — now says so and offers a download, where before it opened an empty
editor that looked as though the file had been lost.

![A video playing in the document pane](assets/changelog/v0.7.0/media-player.png)

### Asking for access, instead of being told it does not exist

Opening a space you have no rights to used to claim the space could not be
found. It now says plainly that it exists and you cannot open it, and offers to
ask for access. The request reaches the people who can actually grant it — the
space's admins, or the admins of a group above it — with a note if you add one.

![The access prompt with a request button](assets/changelog/v0.7.0/request-access.png)

### Also

- Spreadsheets can be edited cell by cell. Formulas, number formats, merged
  cells and column widths survive a save; a workbook holding charts or images
  stays read-only rather than losing them silently.
- The AI chat can create documents, and sees the folders a space really has, so
  it files a new page where the related ones already live. It no longer claims
  to have created something it did not.
- A long AI conversation no longer grows until the browser tab is killed.
