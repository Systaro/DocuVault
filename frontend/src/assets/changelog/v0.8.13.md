The app now works on a phone. Until now the header dropped its links on a small
screen, the file tree could not be opened at all, and while editing the Done
button sat off screen, so an edit could be started but not finished.

On a phone your avatar in the top right opens a menu with the navigation, your
account, dark mode, What's new and Sign out. The file tree opens from the button
left of the logo and stays open while you move through folders; it closes as
soon as you open a document. In the editor the formatting buttons scroll
sideways, so Done and the actions menu stay in reach.

![Three phone screens: the file tree opened from the menu button, a document being edited with Done in reach, and the menu behind the avatar](assets/changelog/v0.8.13/phone.png)

### Also on small screens

- A shared folder link shows its file list as a drawer, so the document gets the
  full width.
- The inbox shows either the list or the selected note, not both squeezed side
  by side.
- The admin menu is a row of chips above the page instead of a card that filled
  the first screen.
- Notifications open across the full width.
- Row menus and comment actions that only appeared when a mouse hovered over
  them are always visible on touch screens.
