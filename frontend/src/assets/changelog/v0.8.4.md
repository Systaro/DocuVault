### New document with AI

In the **New** menu of a folder there is now **New document with AI**. Paste a
meeting transcript, an email or your notes (or dictate them), and the AI writes
the document, gives it a name and saves it in the folder you are in. You can
add what you want in the same box, for example "action items first".

Pick a layout: meeting notes, a summary, a how-to guide, or let the AI decide.
**Like an existing document** copies the headings, tables and fields of another
page, and suggests one from the same or a neighbouring folder, so a new partner
or customer profile looks like the ones next to it. The file is named the way
the other files in the folder are, and an existing file is never overwritten.

The AI only uses what you hand it. The document opens right away, so you can
check it and fix what needs fixing.
