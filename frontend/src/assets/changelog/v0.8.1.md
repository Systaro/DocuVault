### Answers you can check

The assistant is now told how to format its answers: key points in bold,
endpoints, paths and names as code, payloads and config in code blocks. Every
code block has a copy button.

When an answer names a document it used, the name is a link that opens the
document in a new tab. The sources under the answer are now the documents the
answer actually drew on, including the ones the assistant found with its own
searches, listed in the order the answer mentions them.
